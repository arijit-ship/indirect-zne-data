
# Details of _VQE.json File

⚠️ PLACEHOLDER: This values are not concerning for VQE.json files and does not affect the experiment.

| **Section**   | **Key**                                                   | **Type**                 | **Description**                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ------------- | --------------------------------------------------------- | ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **meta**      | `id`                                                      | String                   | Unique UUID identifying the run; also embedded in the output file name.                                                                                                                                                                                                                                                                                                                                                              |
|               | `datetime`                                                | String                   | Run start timestamp (`YYYYMMDD_HHMMSS`).                                                                                                                                                                                                                                                                                                                                                                                             |
|               | `datetime_finished`                                       | String                   | Run finish timestamp (`YYYYMMDD_HHMMSS`).                                                                                                                                                                                                                                                                                                                                                                                            |
|               | `run_index`                                               | Integer                  | Index of this run within a repeated/batched configuration.                                                                                                                                                                                                                                                                                                                                                                           |
|               | `python_version`                                          | String                   | Python interpreter version/build used to execute the run.                                                                                                                                                                                                                                                                                                                                                                            |
|               | `os`                                                      | String                   | Operating system of the host machine.                                                                                                                                                                                                                                                                                                                                                                                                |
|               | `hostname`                                                | String                   | Name of the host machine.                                                                                                                                                                                                                                                                                                                                                                                                            |
|               | `cpu_logical_cores`                                       | Integer                  | Number of logical CPU cores on the host machine.                                                                                                                                                                                                                                                                                                                                                                                     |
|               | `ram_total_gb`                                            | Float                    | Total system RAM (GB) on the host machine.                                                                                                                                                                                                                                                                                                                                                                                           |
| **config**    | `message`                                                 | String                   | Note on where the full step-by-step run history is stored (e.g., `"History is stored in HDF5."`).                                                                                                                                                                                                                                                                                                                                    |
|               | `history`                                                 | Boolean                  | Whether per-evaluation and per-iteration history (parameters, quantum state, cost) is recorded to a separate history file.                                                                                                                                                                                                                                                                                                           |
|               | `run`                                                     | String                   | Algorithm executed. Options: `'vqe'`, `'redundant'`, `'zne'`.                                                                                                                                                                                                                                                                                                                                                                        |
|               | `nqubits`                                                 | Integer                  | Number of qubits in the system.                                                                                                                                                                                                                                                                                                                                                                                                      |
|               | `state`                                                   | String                   | Simulated state representation: `'dmatrix'` (density matrix) or `'statevector'`.                                                                                                                                                                                                                                                                                                                                                     |
|               | `output.file_name_prefix`                                 | String                   | Prefix used for naming output files (data/history/figures).                                                                                                                                                                                                                                                                                                                                                                          |
|               | `output.draw.status`⚠️ PLACEHOLDER.                       | Boolean                  | Whether a circuit-diagram figure is generated for this run.                                                                                                                                                                                                                                                                                                                                                                          |
|               | `output.draw.fig_dpi`⚠️ PLACEHOLDER.                      | Integer                  | Resolution (DPI) of the saved circuit-diagram figure.                                                                                                                                                                                                                                                                                                                                                                                |
|               | `output.draw.type`⚠️ PLACEHOLDER.                         | String                   | File format of the circuit-diagram figure: `'svg'` or `'png'`.                                                                                                                                                                                                                                                                                                                                                                       |
|               | `observable.def`                                          | String                   | Target Hamiltonian type whose ground-state energy VQE estimates. Options: `'custom'`, `'ising'`, `'heisenberg'`.                                                                                                                                                                                                                                                                                                                     |
|               | `observable.coefficients.cn`                              | List of Floats           | Coupling-term coefficients of the target Hamiltonian, length `nqubits-1` (used only when `def='custom'`; overwritten for the built-in `'ising'`/`'heisenberg'` forms).                                                                                                                                                                                                                                                               |
|               | `observable.coefficients.bn`                              | List of Floats           | Per-qubit magnetic-field coefficients of the target Hamiltonian, length `nqubits` (`'custom'` only).                                                                                                                                                                                                                                                                                                                                 |
|               | `observable.coefficients.r`                               | Float                    | Anisotropy coefficient of the target Hamiltonian (`'custom'` only).                                                                                                                                                                                                                                                                                                                                                                  |
|               | `ansatz.layer`                                            | Integer                  | Ansatz circuit depth: number of time-evolution-gate layers. Also sets the number of time parameters to be optimized.                                                                                                                                                                                                                                                                                                                 |
|               | `ansatz.gateset`⚠️ PLACEHOLDER.                           | Integer                  | Number of rotation-gate sets applied per layer; each set is 4 single-qubit rotation gates.                                                                                                                                                                                                                                                                                                                                           |
|               | `ansatz.ugate.type`⚠️ PLACEHOLDER.                        | String                   | Hamiltonian type used inside the time-evolution (U) gate of the ansatz. `'xy-iss'`:1D XY spinchain with X and Z terms.                                                                                                                                                                                                                                                                                                               |
|               | `ansatz.ugate.coefficients.cn`                            | List of Floats           | Coupling-term coefficients for the U-gate Hamiltonian, length `nqubits-1` (`'custom'` type only).                                                                                                                                                                                                                                                                                                                                    |
|               | `ansatz.ugate.coefficients.bn`                            | List of Floats/Integers  | Magnetic-field coefficients for the U-gate Hamiltonian, length `nqubits` (`'custom'` type only).                                                                                                                                                                                                                                                                                                                                     |
|               | `ansatz.ugate.coefficients.r`                             | Float                    | Anisotropy coefficient for the U-gate Hamiltonian (`'custom'` type only).                                                                                                                                                                                                                                                                                                                                                            |
|               | `ansatz.ugate.time.min`                                   | Float                    | Lower bound used when randomly sampling the initial time parameters.                                                                                                                                                                                                                                                                                                                                                                 |
|               | `ansatz.ugate.time.max`                                   | Float                    | Upper bound used when randomly sampling the initial time parameters.                                                                                                                                                                                                                                                                                                                                                                 |
|               | `vqe.iteration`                                           | Integer                  | Configured number of VQEs with independent initial parameters.                                                                                                                                                                                                                                                                                                                                                                       |
|               | `vqe.optimization.status`                                 | Boolean                  | If `false`, the cost is evaluated only once at the initial parameters — no classical optimization loop is run.                                                                                                                                                                                                                                                                                                                       |
|               | `vqe.optimization.algorithm`                              | String                   | Classical optimizer used to minimize the cost function, e.g. `'SLSQP'` or `'COBYLA'`.                                                                                                                                                                                                                                                                                                                                                |
|               | `vqe.optimization.constraint`                             | Boolean                  | Whether a time-ordering constraint (each time parameter must be non-negative and no smaller than the previous one) is enforced during optimization.                                                                                                                                                                                                                                                                                  |
|               | `vqe.optimization.opt_options`                            | Object                   | Solver-specific options passed to the optimizer, e.g. `maxiter`, `disp`, `ftol`.                                                                                                                                                                                                                                                                                                                                                     |
|               | `init_param.value`                                        | String / List of Floats  | `'random'` → parameters are drawn randomly at the start of the run; otherwise a fixed list of initial parameter values is used directly.                                                                                                                                                                                                                                                                                             |
|               | `noise_profile.status`                                    | Boolean                  | Whether the ansatz circuit includes noise gates (noisy simulation) or is built ideally (noiseless).                                                                                                                                                                                                                                                                                                                                  |
|               | `noise_profile.type`                                      | String                   | Noise channel applied. Options include: `'depolarizing'`, `'bitflip'`, `'dephasing'`, `'xznoise'`, `'time-depol'`, `'time-depol-trotter'`, `'time-dephasing'`, `'time-ampdamp'`.                                                                                                                                                                                                                                                     |
|               | `noise_profile.noise_prob`                                | List of Floats (len 4)   | Base noise probability for each gate type, in order `[R-gates, CZ-gate, U-gate, Y-gate]`. **For the U-gate (time-evolution gate) specifically, the probability actually applied is this base value multiplied by the gate's time duration** (`tf - ti`, i.e. the elapsed evolution time for that layer) — the product is used as the effective depolarizing/noise probability for that gate, rather than the raw `noise_prob` value. |
|               | `noise_profile.noise_on_init_param.status`⚠️ PLACEHOLDER. | Boolean                  | Reserved flag for applying noise to the initial parameters themselves; not currently active in this dataset.                                                                                                                                                                                                                                                                                                                         |
|               | `noise_profile.noise_on_init_param.value`⚠️ PLACEHOLDER.  | Integer                  | Placeholder value associated with the (currently inactive) "noise on initial parameters" setting.                                                                                                                                                                                                                                                                                                                                    |
|               | `redundant.identity_factors`⚠️ PLACEHOLDER.               | List of Lists (Integers) | Identity-insertion scaling factors per gate type, in order `[R-gates, CZ-gate, U-gate, Y-gate]`, length 4. Controls how many redundant identity-equivalent gate pairs are inserted for each gate type (used to scale noise for zero-noise extrapolation).                                                                                                                                                                            |
|               | `zne.method`⚠️ PLACEHOLDER.                               | String                   | Zero-noise-extrapolation method used to extrapolate to the zero-noise limit, e.g. `"richardson"`.                                                                                                                                                                                                                                                                                                                                    |
|               | `zne.degree`⚠️ PLACEHOLDER.                               | Integer                  | Polynomial degree used for the extrapolation fit.                                                                                                                                                                                                                                                                                                                                                                                    |
|               | `zne.sampling`⚠️ PLACEHOLDER.                             | String                   | Sampling strategy for choosing extrapolation data points, e.g. `'default'`.                                                                                                                                                                                                                                                                                                                                                          |
|               | `zne.data_points`⚠️ PLACEHOLDER.                          | List of Lists / Null     | Data points used for extrapolation, or `null` if ZNE was not applicable to this run.                                                                                                                                                                                                                                                                                                                                                 |
| **output**    | `exact_sol`                                               | Float                    | Exact ground-state energy of the target Hamiltonian, obtained analytically for comparison against the VQE result.                                                                                                                                                                                                                                                                                                                    |
|               | `initial_cost_history`                                    | List of Floats           | Cost-function value(s) evaluated at the initial parameters, before any optimization is applied.                                                                                                                                                                                                                                                                                                                                      |
|               | `optimized_minimum_cost`                                  | List of Floats           | Final cost-function value(s) reported by the optimizer at convergence (the VQE energy estimate).                                                                                                                                                                                                                                                                                                                                     |
|               | `optimized_parameters`                                    | List of Lists (Floats)   | Optimized parameter vector(s) at convergence: time parameters followed by rotation-angle parameters.                                                                                                                                                                                                                                                                                                                                 |
|               | `noise_details.identity_factors`                          | List of Integers         | Echo of the identity-scaling factors `[R, CZ, U, Y]` actually applied to build this circuit.                                                                                                                                                                                                                                                                                                                                         |
|               | `noise_details.noise_level`                               | List of Integers         | Computed noise level per gate type, derived from the identity-scaling factors.                                                                                                                                                                                                                                                                                                                                                       |
|               | `noise_details.gates_num`                                 | List of Integers         | Number of gates of each type present in the constructed circuit, used to scale the total noise.                                                                                                                                                                                                                                                                                                                                      |
|               | `noise_details.noise_profile`                             | Object                   | Copy of the noise settings (`status`, `type`, `noise_prob`, `noise_on_init_param`) as actually applied to this run.                                                                                                                                                                                                                                                                                                                  |
|               | `noise_details.odd_wires`                                 | Integer                  | Number of qubit wires that received an odd number of noise applications.                                                                                                                                                                                                                                                                                                                                                             |
|               | `noise_details.raw_gate_count`                            | Object                   | Raw count of each gate type in the final circuit: `R`, `CZ`, `U`, `Y`, and `total`.                                                                                                                                                                                                                                                                                                                                                  |
|               | `run_time_sec`                                            | Float                    | Total wall-clock run time, in seconds.                                                                                                                                                                                                                                                                                                                                                                                               |
| **others**    | `observable_string`                                       | String                   | Human-readable Pauli-operator string form of the target Hamiltonian, e.g. `"1 X0 X1 + 1 Z0 + ..."`.                                                                                                                                                                                                                                                                                                                                  |
|               | `time_evolution_gate_hamiltonian_string`                  | List of Strings          | Human-readable Pauli-operator string form of the Hamiltonian used inside the U (time-evolution) gate.                                                                                                                                                                                                                                                                                                                                |
|               | `initial_parameters`                                      | List of Floats           | The randomly generated initial parameter vector used to start the run, before optimization.                                                                                                                                                                                                                                                                                                                                          |
|               | `lie_trotter_details`                                     | List / Null              | Per-layer Trotterization details (time interval, step size, number of Trotter steps) — populated only when Trotterized time-evolution noise is used, otherwise `null`.                                                                                                                                                                                                                                                               |
| **artifacts** | `cost_callings_total`                                     | Integer                  | Total number of times the cost function was evaluated against the simulated quantum backend over the whole run (including the initial pre-optimization evaluation).                                                                                                                                                                                                                                                                  |
|               | `opt_obj.x`                                               | List of Floats           | Optimized parameter vector returned by the optimizer at convergence.                                                                                                                                                                                                                                                                                                                                                                 |
|               | `opt_obj.fun`                                             | Float                    | Final cost-function value at the optimized parameters.                                                                                                                                                                                                                                                                                                                                                                               |
|               | `opt_obj.success`                                         | Boolean                  | Whether the optimizer reported successful convergence.                                                                                                                                                                                                                                                                                                                                                                               |
|               | `opt_obj.message`                                         | String                   | Termination message returned by the optimizer.                                                                                                                                                                                                                                                                                                                                                                                       |
|               | `opt_obj.nit`                                             | Integer                  | Number of major iterations performed by the optimizer.                                                                                                                                                                                                                                                                                                                                                                               |
|               | `opt_obj.nfev`                                            | Integer                  | Number of cost-function evaluations performed by the optimizer during the search.                                                                                                                                                                                                                                                                                                                                                    |
|               | `opt_obj.jac`                                             | List of Floats           | Final gradient (Jacobian) of the cost function at the optimized parameters.                                                                                                                                                                                                                                                                                                                                                          |
|               | `opt_obj.hess_inv`                                        | Object / Null            | Inverse Hessian approximation at convergence, if the chosen optimizer provides one; typically `null` for gradient-free/SLSQP-style optimizers.                                                                                                                                                                                                                                                                                       |
