# About _ZNE.json File

Output from ZNE.

## Top-Level Keys:

| Key | Description |
| :--- | :--- |
|`meta`| System metadata. |
| `config` | Raw configuration input imported from the YAML file. |
| `output` | Results generated from ZNE. |
