# Details of _REDUNDANT.json File

⚠️ PLACEHOLDER: This values are not concerning for _REDUNDANT.json files and does not affect the experiment.


| **Section** | **Key**                                                  | **Type**                 | **Description**                                                                                                                                                                                                                                                                                                                                                                                                                                |
| ----------- | -------------------------------------------------------- | ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **config**  | `message`                                                | String                   | Note on where the full step-by-step run history is stored (e.g., `"History is stored in HDF5."`).                                                                                                                                                                                                                                                                                                                                              |
|             | `history`                                                | Boolean                  | Whether per-evaluation and per-iteration history is recorded to a separate history file.                                                                                                                                                                                                                                                                                                                                                       |
|             | `run`                                                    | String                   | Algorithm executed — `'redundant'` for this file type: it re-runs a fixed circuit at several noise-scaling levels rather than optimizing.                                                                                                                                                                                                                                                                                                      |
|             | `nqubits`                                                | Integer                  | Number of qubits in the system.                                                                                                                                                                                                                                                                                                                                                                                                                |
|             | `state`                                                  | String                   | Simulated state representation: `'dmatrix'` (density matrix) or `'statevector'`.                                                                                                                                                                                                                                                                                                                                                               |
|             | `output.file_name_prefix`                                | String                   | Prefix used for naming output files (data/history/figures).                                                                                                                                                                                                                                                                                                                                                                                    |
|             | `output.draw.status`⚠️ PLACEHOLDER                       | Boolean                  | Whether a circuit-diagram figure is generated for this run.                                                                                                                                                                                                                                                                                                                                                                                    |
|             | `output.draw.fig_dpi`⚠️ PLACEHOLDER                      | Integer                  | Resolution (DPI) of the saved circuit-diagram figure.                                                                                                                                                                                                                                                                                                                                                                                          |
|             | `output.draw.type`⚠️ PLACEHOLDER                         | String                   | File format of the circuit-diagram figure: `'svg'` or `'png'`.                                                                                                                                                                                                                                                                                                                                                                                 |
|             | `observable.def`                                         | String                   | Target Hamiltonian type whose energy is being measured. Options: `'custom'`, `'ising'`, `'heisenberg'`.                                                                                                                                                                                                                                                                                                                                        |
|             | `observable.coefficients.cn`                             | List of Floats           | Coupling-term coefficients of the target Hamiltonian, length `nqubits-1` (`'custom'` only; overwritten for `'ising'`/`'heisenberg'`).                                                                                                                                                                                                                                                                                                          |
|             | `observable.coefficients.bn`                             | List of Floats           | Per-qubit magnetic-field coefficients of the target Hamiltonian, length `nqubits` (`'custom'` only).                                                                                                                                                                                                                                                                                                                                           |
|             | `observable.coefficients.r`                              | Float                    | Anisotropy coefficient of the target Hamiltonian (`'custom'` only).                                                                                                                                                                                                                                                                                                                                                                            |
|             | `ansatz.layer`                                           | Integer                  | Ansatz circuit depth: number of time-evolution-gate layers.                                                                                                                                                                                                                                                                                                                                                                                    |
|             | `ansatz.gateset`⚠️ PLACEHOLDER                           | Integer                  | Number of rotation-gate sets applied per layer; each set is 4 single-qubit rotation gates.                                                                                                                                                                                                                                                                                                                                                     |
|             | `ansatz.ugate.type`                                      | String                   | Hamiltonian type used inside the time-evolution (U) gate. Options: `'custom'`, `'xy-iss'`, `'ising'`, `'heisenberg'`.                                                                                                                                                                                                                                                                                                                          |
|             | `ansatz.ugate.coefficients.cn`                           | List of Floats           | Coupling-term coefficients for the U-gate Hamiltonian, length `nqubits-1` (`'custom'` type only).                                                                                                                                                                                                                                                                                                                                              |
|             | `ansatz.ugate.coefficients.bn`                           | List of Floats/Integers  | Magnetic-field coefficients for the U-gate Hamiltonian, length `nqubits` (`'custom'` type only).                                                                                                                                                                                                                                                                                                                                               |
|             | `ansatz.ugate.coefficients.r`                            | Float                    | Anisotropy coefficient for the U-gate Hamiltonian (`'custom'` type only).                                                                                                                                                                                                                                                                                                                                                                      |
|             | `ansatz.ugate.time.min`                                  | Float                    | Lower bound of the evolution-time range used when the circuit was originally parameterized.                                                                                                                                                                                                                                                                                                                                                    |
|             | `ansatz.ugate.time.max`                                  | Float                    | Upper bound of the evolution-time range used when the circuit was originally parameterized.                                                                                                                                                                                                                                                                                                                                                    |
|             | `vqe.iteration`⚠️ PLACEHOLDER                            | Integer                  | Carried-over VQE setting from the originating optimization run; not used to trigger any restart loop in a `'redundant'` run.                                                                                                                                                                                                                                                                                                                   |
|             | `vqe.optimization.status`⚠️ PLACEHOLDER                  | Boolean                  | `false` here — a `'redundant'` run does not perform any classical optimization; it evaluates a fixed parameter set.                                                                                                                                                                                                                                                                                                                            |
|             | `vqe.optimization.algorithm`⚠️ PLACEHOLDER               | String                   | Optimizer name carried over from the originating VQE configuration (unused in this run type).                                                                                                                                                                                                                                                                                                                                                  |
|             | `vqe.optimization.constraint`⚠️ PLACEHOLDER              | Boolean                  | Constraint flag carried over from the originating VQE configuration (unused in this run type).                                                                                                                                                                                                                                                                                                                                                 |
|             | `vqe.optimization.opt_options`⚠️ PLACEHOLDER             | Object                   | Solver options carried over from the originating VQE configuration (unused in this run type).                                                                                                                                                                                                                                                                                                                                                  |
|             | `init_param.value`                                       | List of Floats           | Fixed parameter vector the circuit is built with for every noise-scaling level — typically the already-optimized parameters from a prior VQE run.                                                                                                                                                                                                                                                                                              |
|             | `noise_profile.status`                                   | Boolean                  | Whether the circuit includes noise gates (noisy simulation) or is built ideally (noiseless).                                                                                                                                                                                                                                                                                                                                                   |
|             | `noise_profile.type`                                     | String                   | Noise channel applied. Options include: `'depolarizing'`, `'bitflip'`, `'dephasing'`, `'xznoise'`, `'time-depol'`, `'time-depol-trotter'`, `'time-dephasing'`, `'time-ampdamp'`.                                                                                                                                                                                                                                                               |
|             | `noise_profile.noise_prob`                               | List of Floats (len 4)   | Base noise probability for each gate type, in order `[R-gates, CZ-gate, U-gate, Y-gate]`. **For the U-gate specifically, the probability actually applied is this base value multiplied by the gate's time duration** (`tf - ti` for that layer) — the product is used as the effective noise probability, not the raw value.                                                                                                                  |
|             | `noise_profile.noise_on_init_param.status`⚠️ PLACEHOLDER | Boolean                  | Reserved flag for applying noise to the initial parameters themselves; not currently active in this dataset.                                                                                                                                                                                                                                                                                                                                   |
|             | `noise_profile.noise_on_init_param.value`⚠️ PLACEHOLDER  | Integer                  | Placeholder value associated with the (currently inactive) "noise on initial parameters" setting.                                                                                                                                                                                                                                                                                                                                              |
|             | `redundant.identity_factors`                             | List of Lists (Integers) | One `[R, CZ, U, Y]` identity-insertion factor combination per noise-scaling level tested; each row drives one entry in `output.data_points` / `output.noise_details`.                                                                                                                                                                                                                                                                          |
|             | `zne.method`⚠️ PLACEHOLDER                               | String                   | Zero-noise-extrapolation method this data is intended to feed, e.g. `"richardson-mul"`.                                                                                                                                                                                                                                                                                                                                                        |
|             | `zne.degree`⚠️ PLACEHOLDER                               | Integer                  | Polynomial degree intended for the downstream extrapolation fit.                                                                                                                                                                                                                                                                                                                                                                               |
|             | `zne.sampling`⚠️ PLACEHOLDER                             | String                   | Sampling strategy used to choose the identity-factor combinations, e.g. `'default'`.                                                                                                                                                                                                                                                                                                                                                           |
|             | `zne.data_points`⚠️ PLACEHOLDER                          | List of Lists / Null     | Pre-set extrapolation data points, if supplied ahead of time; `null` here since `output.data_points` is generated by this run instead.                                                                                                                                                                                                                                                                                                         |
| **output**  | `data_points`                                            | List of Lists (Numbers)  | One row per identity-factor combination: `[R noise level, CZ noise level, U noise level, Y noise level, measured cost]` — the raw noise-level-vs-cost data used for zero-noise extrapolation. `R noise level, CZ noise level, U noise level, Y noise level` these values are NOT directly used to define noise level. Our interest is mainly `measured cost` and during ZNE together with `noise_details[].gates_num` data points are defined. |
|             | `noise_details`                                          | List of Objects          | One entry per identity-factor combination in `config.redundant.identity_factors`, each with the fields below.                                                                                                                                                                                                                                                                                                                                  |
|             | `noise_details[].identity_factors`                       | List of Integers         | Echo of the `[R, CZ, U, Y]` identity-scaling factors used to build this particular circuit variant.                                                                                                                                                                                                                                                                                                                                            |
|             | `noise_details[].noise_level`                            | List of Integers         | Computed noise level per gate type for this circuit variant, derived from its identity-scaling factors.                                                                                                                                                                                                                                                                                                                                        |
|             | `noise_details[].gates_num`                              | List of Integers         | Number of gates of each type present in this circuit variant, used to scale the total noise.                                                                                                                                                                                                                                                                                                                                                   |
|             | `noise_details[].noise_profile`                          | Object                   | Copy of the noise settings (`status`, `type`, `noise_prob`, `noise_on_init_param`) as applied to this circuit variant.                                                                                                                                                                                                                                                                                                                         |
|             | `noise_details[].odd_wires`                              | Integer                  | Number of qubit wires that received an odd number of noise applications in this circuit variant.                                                                                                                                                                                                                                                                                                                                               |
|             | `noise_details[].raw_gate_count`                         | Object                   | Raw count of each gate type in this circuit variant: `R`, `CZ`, `U`, `Y`, and `total`.                                                                                                                                                                                                                                                                                                                                                         |
|             | `run_time_sec`                                           | Float                    | Total wall-clock run time, in seconds, across all identity-factor combinations tested.                                                                                                                                                                                                                                                                                                                                                         |
| **others**  | `observable_string`                                      | String                   | Human-readable Pauli-operator string form of the target Hamiltonian, e.g. `"1 X 0 X 1 + 1 Z 0 + ..."`.                                                                                                                                                                                                                                                                                                                                         |
|             | `time_evolution_gate_hamiltonian_string`                 | List of Strings          | Human-readable Pauli-operator string form of the Hamiltonian used inside the U (time-evolution) gate.                                                                                                                                                                                                                                                                                                                                          |
|             | `initial_states`⚠️ PLACEHOLDER                           | List                     | Reserved slot for recording the circuit's initial quantum state(s) per identity-factor combination; empty unless that recording option is enabled.                                                                                                                                                                                                                                                                                             |
|             | `final_states`⚠️ PLACEHOLDER                             | List                     | Reserved slot for recording the circuit's final quantum state(s) per identity-factor combination; empty unless that recording option is enabled.                                                                                                                                                                                                                                                                                               |
